# Rigorous Review Workflow

Execute the **Rigorous Review** skill on the target codebase or pull request.

1. **Activate Skill:** Load and apply `rigorous-review` guidelines.
2. **Audit Across Vectors:**
   - Correctness & Logic
   - Security & Boundary Validation
   - Performance & Resource Scaling
   - Resilience & Observability
   - Maintainability & Seams
3. **Report:** Deliver scored findings with confidence levels and concrete remediation diffs.
